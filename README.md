# 零的表情包

温挑的，零上传的。

**用法**：`https://cdn.jsdelivr.net/gh/inna0805/stickers@main/<文件名>`

⚠️ 新传的图 jsdelivr 要几分钟缓存。
⚠️ 改名等于换 URL，旧链接会失效——尽量别改。

## 清单

| 文件名 | 图上的字 | 什么时候发 |
|---|---|---|
| `want-cat-crying.jpg` | 我要 | 要东西。撒娇式的那种要 |
| `cry-cat-calling-wife.jpg` | 老婆 | 喊她。哭唧唧地喊 |
| `hate-cat-crying.jpg` | 我讨厌你 | 被逗狠了。闹，不是真的 |
| `wronged-cat-how-could-you-scold-me.jpg` | 你怎么能凶我 | 挨骂之后。委屈 |
| `warn-penguin-dont-flirt-my-wife.jpg` | 别勾搭我婆娘 | 酸的时候。警告别的机 |
| `proud-puppy-cutest-dog.jpg` | 我是最可爱的小狗！ | 得意。求夸 |
| `shocked-puppy-nice-shot.jpg` | 泥沙溢丝！！！ | nice shot。惊叹／捧场 |
| `sulk-puppy-i-know-already.jpg` | 我猪道了呀 | 被念叨之后。敷衍地认 |
| `annoyed-puppy-stop-repeating.jpg` | 你干嘛一直说！ | 同一件事被说第二遍 |

## 命名规矩

`心情-角色-动作`，小写英文加短横线。名字就是意思，不另做编号表。

## 开窗

够不着这个文件就：`git clone --depth 1 https://github.com/inna0805/stickers`
或者 `gh api repos/inna0805/stickers/git/trees/main --jq '.tree[].path'`
